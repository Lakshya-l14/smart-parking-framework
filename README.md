## Automated Smart Parking Framework

A web-based smart parking management system that provides
a structured way to view parking infrastructure and manage
parking slot information.

## Technologies Used

- HTML
- CSS and JavaScript
- Node.js
- Express.js
- SQLite

## Features

- Parking slot management
- Parking location information
- Booking-related functionality
- SQLite database integration

## Prerequisites

- Node.js and npm
- Git

## Installation

1. Clone this repository.
2. Open the project folder in a terminal.
3. Install dependencies:

   npm install

4. Start the application:

   npm start

5. Open the following address in a browser:

   http://localhost:3000

## Database

The application uses SQLite.

Follow the database initialization instructions in this
repository before using the application on a new computer.
